# T50 全国地区与覆盖登记最小源码

2026-10-12：本批只提供本地纯模型与空登记矩阵；未执行测试、Lint、Type Check、Build、校验或采集。原 T50 持久来源后台、分母核验、权限及真实审核发布仍未完成，不能将源码称为全国资料已采齐。

## 实施前冻结的契约

- 复用既有 `data/research/source_registry_2026.json` 与只读验证器中的 `cn_region_01`–`cn_region_31`、`hk`、`mo`、`tw`，分别对应大陆31个省级地区与港澳台。这些是项目内部键，**不是官方行政区划代码**。不会把研究文件导入生产或改写原登记记录。
- region 及普通高考生源 scope 分开。普通高考 scope 仅允许大陆键；港澳台本地招生路径分别保存，不套用省线。authority 引用属于 scope 附加属性；兵团只可作为新疆 `cn_region_31` 的子范围，不增加省级分母或复制地区。
- `CoverageUnit` 精确按地区×参考2026×资料类型×路径登记。七类型为机构名录、省线、分布、录取统计、招生政策、培养方案、毕业结果。空矩阵固定34×7＝238格。HK/MO/TW 的普通高考省线/分布六格为 `not_applicable`；本地录取统计与政策使用各自路径，不能把不适用当缺采或全国省线。
- 研究来源数、待审来源数、合成夹具数、已审事实数、已发布事实数分开，计数不等同资料覆盖率。待审来源必须包含在研究来源数中；当前已审/已发布事实固定0。没有可信分母核验及已发布接缝，本批 `expected_total=null`、`coverage_ratio=null`、`collection_complete=false`，不能传数字伪造完整率。
- 缺失状态仅 `not_collected`、`source_candidate_only`、`not_applicable`。没有来源时明确未采集；有研究来源仅显示来源候选，不能称事实已审。合成夹具计数不改变真实覆盖状态。不适用格不允许来源/夹具计数；具体资料未公布、读取失败等原始细节继续留在旧研究记录，不能被空矩阵改写为新调查结论。

## 文件与行为

新增 `services/api/app/statistics/__init__.py`、`regions.py`、`coverage.py`。无网络、文件读取、数据库、审核发布、身份路由或默认应用装配。`empty_matrix()` 每次构造新的238格不可变数据，不缓存用户状态。本地严格 Pydantic 模型复用 `CatalogModel`；函数入口重新验证模型，不能借 `model_construct` 绕过 scope 约束。

共享候选基类由 `statistics/candidates.py` 单独负责，不由覆盖模型将候选变成已发布事实。
