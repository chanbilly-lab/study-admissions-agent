## 展示契约与修改范围

保留Vue3/TypeScript/Vite与原API、数据契约、权限和业务控制器，不添加依赖。M0合成身份/画像确认/四态/证据/未确认草案不变；reference明确本地真实参考、范围与缺项；英国研究候选不接页面或资格。所有分数、年份、状态与来源仍来自原响应，不写假学校、总量、覆盖率或录取指标。

本批只调整App.vue、styles.css、M0 EvidenceDialog及5个参考Vue页面：ReferenceView、StatisticsView、CutoffResults、CurriculaView、OutcomesView。统一现有青绿色/浅底主题、可读字号、按钮与焦点、移动布局；增强参考导航/筛选/查询状态、分数/用途/来源信息层次，技术hash可渐进展开但核心未知/复核范围不能隐去。M0下一步提示只从现有配置/画像dirty/所选项目/结果/草案派生，不自动确认或调用API；保留原四阶段锚点。

具体相关修正：期限null改“未知·缺少期限依据”，不推断未公布；省线分类明确含分段线；M0显示筛选外仍选项目数量，检查的原选择集合不变；演示证据关闭/卸载恢复焦点并拒迟到打开，复用项目内现有dialog做法。普通导航按钮保留aria-pressed，不伪造未实现完整键盘行为的ARIA tabs。
