正式运营主体名称/联系方式、权利请求渠道、处理与核验责任人、供应商地域、上线审查仍待落实。真实处理默认关闭；不能将合成测试告知或开发者审查当作正式法律/隐私复核。

## 告知草案（供人工复核）

- 核心用途仅为学生确认的本科咨询资料、确定性资格和准备计划。外部模型、营销与第三方共享未获本条同意，接口关闭。
- 只保存必要的成年年龄区间声明、告知版本、用途确认及撤回状态；不收完整出生日期或身份证/护照影像。未成年/未知的年龄拒绝路径不保存新的儿童年龄声明。
- 未来画像和成绩、附件分别按已选产品上限及更短必要期限处理；本 Task 不采集这些内容。登录会话与安全机制另有必要处理说明，不能把公开浏览称为完全不处理个人信息。
- 用户可在隐私设置撤回核心用途确认。撤回立即使后续相应用途处理失效，隐私设置和退出仍可使用；删除请求和法定限制保留另按正式流程处理。
- 告知/政策变更及成年声明变更需要重新确认。本人确认不能改变角色、owner、核验状态或业务开放状态。
- 本草案缺少正式主体/权利渠道及责任人签署，不可作为生产告知；默认显示未就绪，不接收真实年龄或用途确认。

## T08 数据契约（先列后实现）

公开告知输出当前政策、用途、版本和 hash、文本、是否合成及 readiness；未配置时返回明确未就绪，不臆造正式主体。身份设置输出 age declaration / assurance、revision、当前 notice、consent 引用、核心用途决定与原因；`private_business_available`始终 false。只有合成离线配置可验完整成年流程。生产未就绪拒绝写入，但撤回已有记录仍可用。

拟定接口：`GET /v2/privacy/notices/current`、`GET /v2/me/admission`、`POST /v2/me/age-declarations`、`POST /v2/me/consents`、`DELETE /v2/me/consents/{consent_id}`。写入使用既有 Cookie、固定 Origin 和会话 CSRF；额外 owner、verified、角色及多用途一键同意字段拒绝。核心用途名 `core_consultation`；其他用途不实现。

年龄声明枚举 `unknown / under_14 / 14_17 / 18_plus`，本人声明只能产生 `declared`，不能产生 `verified`。缺少声明/当前告知/确认、未成年核验不可用、撤回、配置关闭或策略变更一律不准入。接受成年正向声明及同意使用 expected revision / 当前notice防陈旧覆盖；非成人或未知声明只减少许可并拒绝，不受旧revision/notice或未就绪阻挡：已有成年声明则原子清除并使旧确认失效，无既有记录不新增年龄关联行；撤回按本人记录幂等且不以旧 revision 阻挡。告知版本不可变；告知 hash 与保存的实际文本一致，不编造文件哈希。

隐私服务与私有用途 guard 在当前数据库事务重验账户、会话及最新准入，使用一致账户锁序，撤回与后续执行有明确提交次序。缓存不能保存许可；延迟处理必须重新调用 guard。T07 的对象 owner/角色与本用途门槛同时需要，准入不授予角色。T08验收时尚无共享接口；T09已独立实现合成metadata共享，真实业务、worker和清理作业仍未实现。

## 官方依据的边界

香港儿童指引强调清楚告知和必要收集，不能直接套用大陆14岁边界。[PCPD儿童资料指引](https://www.pcpd.org.hk/english/resources_centre/publications/files/guidance_children_e.pdf)。澳门和台湾的民事能力、同意及域外适用须结合身份和实际数据流复核；本轮不作统一法律结论。
